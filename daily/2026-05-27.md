# Daily Embodied Works — VLA Edition (2026-05-27)

A curated digest of recently released / updated embodied works on
Vision-Language-Action (VLA) models. Highlighted entries (★) are
those I find particularly well-designed, well-motivated, or likely
to influence the near-term research direction.

This cycle is a **grounded roundup** pinned to actual arXiv releases
surfaced this period. After two cycles about the *conditioning interface*
(geometry, gesture, visual primitives entering the action input), the
signal this period swings to the **other axis of the policy — time and
state.** The freshest design is **EvoScene-VLA** (2605.21862, May 21), a
chunked policy that carries a *geometry-aware, action-updated scene
belief inside the action decoder* — memory + world-model prediction +
3D structure fused into a single recurrent mechanism. Around it the
memory line finally **consolidates**: it gets a principled non-Markovian
*benchmark* (**RoboMME**, 2603.04639, four memory types × 16 tasks), a
*multi-granularity* representation good for ~15-minute horizons (**MEM**,
2603.03596), and a *declarative scene + episodic* split built for mobile
manipulation (**EchoVLA**, 2511.18112). Two adjacent fresh items round it
out — **Health-Conditioned VLA** (2605.16056, May 15), which conditions
the policy on a per-joint health vector for malfunction-aware control,
and **Thinking in Text and Images** (2605.00438, May 1), which interleaves
textual subgoals with visual keyframes for long-horizon manipulation.
The through-line: **memory stops being a bolt-on token cache and becomes
architecturally first-class — with a benchmark to measure it.**

## 1. VLA Model Design & Architecture

- ★ **EvoScene-VLA: Evolving Scene Beliefs Inside the Action Decoder for
  Chunked Robot Control** (arXiv:2605.21862, May 21, 2026). The freshest
  and best-designed entry of the cycle, and the rare paper that fuses three
  threads this digest has tracked separately. The diagnosis is sharp:
  chunked VLAs predict multi-step actions conditioned on a *single* visual
  observation, but the robot's own actions cause contact, occlusion, and
  object motion — so the geometry later steps depend on changes *before*
  the next visual update arrives. EvoScene-VLA carries a **recurrent scene
  prefix** that propagates a geometry-aware scene state across chunks, so
  each control call starts from a *prior* reflecting both recent actions
  and fresh visual evidence. Two training-only modules do the work: a
  **Geometric Anchor** aligns scene tokens with per-pixel depth and
  scene-level features, and a **Scene Predictor** maps the current scene +
  action sequence to *future* scene representations, supervised by
  future-frame 3DFM features. On 31 RoboTwin tasks it lifts average success
  87.2%→89.1% (fixed) and 86.1%→88.5% (randomized), and tops all baselines
  on the Galaxea R1-Lite real robot. It is simultaneously a memory
  mechanism (§3), a world-model-in-the-decoder (§4), and a PointACT-lineage
  geometry argument (§1) — the cleanest unification this cycle.

- **Health-Conditioned VLA for Malfunction-Aware Robot Control**
  (arXiv:2605.16056, May 15, 2026). Conditions a pretrained VLA on an
  explicit **per-joint health vector** (0.0 = locked, 1.0 = full health,
  encoding operating-angle and torque capability) via a lightweight
  **Health Projector** injected into the VLA-Adapter architecture and
  trained on malfunction data. Well-motivated for the deployment regime
  everyone hand-waves past: real hardware degrades, and a policy that
  cannot adapt its plan to a weak or locked joint simply fails. A clean,
  minimal conditioning interface for a problem the benchmark-chasing
  literature ignores. (Cross-listed in §8 as an applications/robustness
  contribution.)

- **GesVLA: Gesture-Aware VLA with Embedded Representations**
  (arXiv:2605.22812; carried highlight). Last cycle's freshest release —
  adds *gesture* as a parallel instruction modality embedded directly in
  the latent space via a dual-VLM design, with a cheap rendered-hand data
  pipeline. Still the standout attack on instruction ambiguity (see §2).

- **Action with Visual Primitives (AVP)** (arXiv:2605.22183; carried
  highlight). The VLM emits *visual-primitive tokens* that condition action
  generation — the sweet spot between lossy text and ungrounded action
  tokens. Reads as the 2D-primitive sibling to PointACT's 3D geometry and
  EvoScene-VLA's scene-state interface.

- **PointACT: Multi-Scale Point-Action Interaction** (arXiv:2605.21414;
  carried). A dual-system, 3D-aware policy decoding from hierarchical
  point-cloud structure — the geometry-in-the-action-interface anchor that
  EvoScene-VLA now extends *through time*.

- *(Carried design anchors: CapVector — transferable capability vectors in
  parameter space (2605.10903); ACoT-VLA — action chain-of-thought
  (2601.11404); MMaDA-VLA (2603.25406, discrete-diffusion, 98.0% LIBERO /
  4.78 CALVIN); LLaDA-VLA (2509.06932); Evo-1 (2511.04555); SD-VLA
  (2602.03983); VITA-VLA (2510.09607); TinyVLA, SmolVLA, π₀ / π₀-FAST,
  OpenVLA-OFT.)*

## 2. Instruction Following & Language Grounding

- ★ **GesVLA** (arXiv:2605.22812; carried highlight; see §1). As a
  grounding contribution it remains the cycle's sharpest: the "illusion of
  instruction following" is partly a *modality* problem — language cannot
  disambiguate among identical objects — and a grounded gesture channel
  attacks that root cause rather than patching attention.

- **Grounding Hierarchical VLA Through Explicit Language-Action Alignment**
  (arXiv:2604.05614; carried highlight). Trains the language head to *agree*
  with the trajectory via contrastive language↔trajectory ranking plus
  offline preference learning. The right framing for human-robot
  collaboration: narration must match action.

- **ProGAL-VLA: Grounded Alignment through Prospective Reasoning**
  (arXiv:2604.09824; carried). Aligns grounding by reasoning *prospectively*
  about the intended outcome before committing to action.

- **When Vision Overrides Language: Counterfactual Failures in VLAs**
  (arXiv:2602.17659; carried highlight). Still the sharpest diagnostic — the
  eval lens through which every entry here should be read. Pairs with the
  new counterfactual benchmark LIBERO-CF (§7).

- *(Carried grounding anchors: CAST — counterfactual relabeling
  (2508.13446); train-free attention recalibration (2603.06001);
  Actions-as-Language (2509.22195); LangForce — Bayesian decomposition via
  latent action queries (2601.15197); Point What You Mean (2512.18933).)*

## 3. VLA with Memory & Long-Horizon Reasoning

- ★ **MEM: Multi-Scale Embodied Memory for VLAs** (arXiv:2603.03596,
  Mar 2026). The best-motivated *representation* result in the memory line:
  a robot's memory must hold past events at **multiple granularities** —
  video-based short-horizon memory (compressed via a video encoder) to
  recover from occlusion, and text-based long-horizon memory for abstracted
  semantic state (e.g., which recipe stages are done). Trained on a diverse
  robot + non-robot corpus, MEM VLAs solve tasks requiring **up to fifteen
  minutes** of memory, handle partial observability, and do in-context
  strategy adaptation. The mixed-modal, multi-scale design is the right
  answer to "what should a long-horizon policy remember, and at what
  resolution" — a complement to the discrete-token (VQ-Memory) and recursive
  belief (RB-VLA) bets.

- ★ **EchoVLA: Synergistic Declarative Memory for VLA-Driven Mobile
  Manipulation** (arXiv:2511.18112). Pushes memory past tabletop into
  *mobile* manipulation, where the agent must coordinate navigation and
  manipulation under shifting spatial context. A brain-inspired
  **declarative memory** splits into a **scene memory** (spatial-semantic
  maps) and an **episodic memory** (task-level experiences with multimodal
  context); the two are stored/updated/retrieved independently and fused via
  coarse- and fine-grained attention to guide base-arm diffusion policies.
  The clean scene-vs-episodic factorization is the well-motivated part —
  spatial layout and task history are different memories with different
  update rules, and forcing them into one token cache loses both.

- ★ **EvoScene-VLA** (arXiv:2605.21862; see §1). Read here as the *implicit*
  end of the memory spectrum: rather than an external retrievable store, it
  keeps a recurrent, action-updated scene belief *inside* the decoder so
  short-horizon geometric state survives between visual updates. The
  in-decoder vs. external-store contrast with MEM/EchoVLA is the cycle's
  cleanest memory-design axis.

- **Thinking in Text and Images: Interleaved Vision–Language Reasoning
  Traces for Long-Horizon Manipulation** (arXiv:2605.00438, May 2026).
  Alternates *textual subgoals* with *visual keyframes* as an explicit
  reasoning trace, fixing the failure where existing policies either hide
  planning in latent state or expose only one modality. The interleaved
  text+image trace is a natural bridge between ACoT-VLA's action-CoT and the
  world-model line's future-frame prediction.

- **VLAs-as-Tools: Tool-Aligned VLA Models for Long-Horizon Agents**
  (arXiv:2605.13119; carried highlight). A VLM agent (planning, progress
  tracking, recovery) orchestrating a family of specialized VLA tools — the
  most deployable long-horizon framing, now with RoboMME (§7) as a yardstick.

- *(Carried memory anchors: ChemBot — dual-layer long-term memory
  (2604.15671); VQ-Memory — vector-quantized proprioceptive tokens on
  non-Markovian suites (2603.09513); LongBench — real-world long-horizon eval
  (2604.16788); RB-VLA — recursive belief state (2602.20659); LoHo-Manip
  (2604.21924); MemoryVLA (2508.19236); SD-VLA + LIBERO-memory (2602.03983);
  TempoFit (2603.07647); MAP-VLA (2511.09516); RoboCerebra (2506.06677).)*

## 4. World-Model-Based VLA

- ★ **EvoScene-VLA's Scene Predictor** (arXiv:2605.21862; see §1). Worth
  flagging in this section too: the Scene Predictor *is* a compact,
  in-the-loop world model — it predicts future scene representations from
  the current scene + planned action chunk, supervised by future-frame 3DFM
  features. Unlike pixel-space video world models, it predicts in a
  geometry-aware *feature* space, which is exactly the "avoid pixel-level
  modeling" lesson VLA-MBPO argued for — here baked into the decoder rather
  than run as a separate imagined rollout.

- **Towards Practical World Model-based RL for VLAs (VLA-MBPO)**
  (arXiv:2603.20607; carried highlight). Names the three obstacles to
  in-imagination RL — pixel-level modeling, multi-view consistency,
  compounding error — and engineers around each (unified multimodal world
  model, interleaved view decoding, chunk-level branched rollout). The
  "make it practical" anchor.

- **WoVR: World Models as Reliable Simulators for Post-Training VLAs**
  (arXiv:2602.13977; carried). The simulator-reliability prerequisite
  VLA-MBPO's rollout machinery assumes.

- **WMPO: World Model-based Policy Optimization for VLAs**
  (arXiv:2511.09515; carried). The policy-optimization recipe over a learned
  world model.

- **World Action Models: The Next Frontier in Embodied AI**
  (arXiv:2605.12090; carried highlight). The position/survey that named the
  line (joint distribution over future states and actions).

- **Reinforcing VLAs in Task-Agnostic World Models** (arXiv:2605.12334;
  carried highlight). The task-agnostic stance — one world model amortized
  across the skill repertoire — still the cleanest open tension against the
  co-trained camp (World-VLA-Loop, VLAW).

- *(Carried world-model anchors: World-VLA-Loop (2602.06508); VLAW
  (2602.12063); GigaBrain-0.5M* / RAMP (2602.12099); World-Gymnast
  (2602.02454); RISE (2602.11075); VLA-JEPA (2602.10098);
  Do-World-Action-Models-Generalize (2603.22078); World Model for Robot
  Learning survey (2605.00080).)*

## 5. Latent Action Embeddings / Action Representation

- ★ **LARY: A Latent Action Representation Yielding Benchmark for
  Generalizable Vision-to-Action Alignment** (arXiv:2604.11689). The piece
  the latent-action line was missing — a *benchmark* for whether a learned
  latent action actually generalizes across the vision→action gap, rather
  than another method evaluated on its own bespoke setup. A measurement
  contribution that should discipline the ALAM/JALA/UniVLA family the way
  RoboMME (§7) is about to discipline the memory line.

- **Latent Action World Models for Control with Unlabeled Trajectories**
  (arXiv:2512.10016). Learns a *shared latent action* that aligns observed
  control signals with actions inferred from passive observation, so one
  dynamics model trains on large unlabeled trajectories with only a small
  action-labeled set — ~10× fewer labeled samples on DMC. The data-efficiency
  argument that ties the latent-action line to the world-model line.

- **ALAM: Algebraically Consistent Latent Action Model** (arXiv:2605.10819;
  carried highlight). Algebraic-consistency constraints on how latent actions
  *compose*: MetaWorld MT50 47.9%→85.0%, LIBERO 94.1%→98.1%. Structure, not
  codebook capacity, is the bottleneck.

- **JALA: Joint-Aligned Latent Action — Scalable VLA Pretraining in the
  Wild** (arXiv:2602.21736; carried). Scales latent-action pretraining to a
  7.5M-clip / >2,000-hour corpus by aligning a predictive action embedding to
  inverse dynamics and real actions. The data-scale proof for the LAPA
  lineage — and exactly the kind of method LARY should now stress-test.

- *(Carried latent-action anchors: WholebodyVLA — unified latent VLA for
  whole-body loco-manipulation (ICLR 2026, OpenDriveLab); UniLACT —
  depth-aware RGB latent actions (2602.20231); Hierarchical Latent Action
  Model (2603.05815); LAPA (2410.11758); Latent Action Pretraining via World
  Modeling (2509.18428); UniVLA (2505.06111).)*

## 6. Reinforcement Learning for VLA

- ★ **FPO: Reinforcement Fine-Tuning of Flow-Matching Policies for VLAs**
  (arXiv:2510.09976; carried highlight). Resolves the incompatibility between
  flow-matching action heads and PPO-style updates with a **likelihood-free
  policy ratio** from per-sample changes in the conditional flow-matching
  objective, plus latent-space credit assignment, a clipped surrogate,
  multi-step latent exploration, and a Q-ensemble. The principled answer the
  π₀-style flow-policy crowd needed for *online* RL without collapse.

- **Simple Recipe Works: VLAs are Natural Continual Learners with RL**
  (arXiv:2603.11653; carried highlight). RL post-training sidesteps the
  forgetting that plagues SFT — still the result that should change your
  default post-training recipe.

- **Towards Long-Lived Robots: Continual Learning VLAs via RFT**
  (arXiv:2602.10503; carried). RL fine-tuning lets a VLA accumulate skills
  over a long deployment lifetime — the longitudinal complement to the above.

- **VLA-RFT: RL Fine-Tuning with Verified Rewards in World Simulators**
  (arXiv:2510.00406; carried). The bridge between the §4 world-model substrate
  and a well-posed RL signal; verified rewards keep imagined-rollout RL honest.

- *(Carried RL anchors: Adaptive Offline RL for VLA Flow Models (2509.04063);
  VLA-RL — scalable RL on a VLA backbone (2505.18719); SimpleVLA-RL / PRIME-RL
  (ICLR 2026); RLinf embodied-RL infrastructure.)*

## 7. Benchmarks, Simulators & Evaluation

- ★ **RoboMME: Benchmarking and Understanding Memory for Robotic Generalist
  Policies** (arXiv:2603.04639). The memory benchmark the §3 line has been
  validating against in pieces — now standardized. 16 manipulation tasks
  under a four-way **memory taxonomy**: *Counting* (temporal memory — count
  placed cubes and stop), *Permanence* (spatial memory under occlusion),
  *Reference* (object memory under varied cues), and *Imitation* (procedural
  memory — reproduce a demonstrated behavior). All tasks are **non-Markovian
  by construction** (the relevant past is no longer visible), with **770k**
  training timesteps and **14 memory-augmented variants on a π0.5 backbone**
  spanning representations × integration strategies. The most useful thing to
  happen to the memory line this cycle: it turns "our policy remembers" from
  an anecdote into a measurement, and the taxonomy gives RB-VLA / VQ-Memory /
  MemoryVLA / MEM / EchoVLA a common axis.

- **LIBERO-CF & CEBench** (surfaced this period). LIBERO-CF is a
  *counterfactual* benchmark for language-following — visually plausible but
  linguistically distinct instructions under controlled counterfactuals,
  operationalizing the *When-Vision-Overrides-Language* diagnostic (§2).
  CEBench spans single-arm, bimanual, and mobile-bimanual embodiments in sim
  and real (14.4k sim demos / 36 tasks; 1.6k real demos / 8 tasks) with
  explicit domain randomization — a practicality-first complement.

- **Vision-Language-Action in Robotics: A Survey of Datasets, Benchmarks,
  and Data Engines** (arXiv:2604.23001; carried highlight). The data-centric
  survey arguing future gains hinge on *data engines + structured evaluation*
  more than architecture. RoboMME and LIBERO-CF are exactly the "structured
  evaluation" half it calls for.

- **RobotArena∞ (2510.23571; carried) & VLA-Perf (2602.18397; carried).**
  Real-to-sim scalable benchmarking, and the inference-latency study the
  field still under-reports.

- *(Carried benchmark anchors: Seeing Realism from Simulation — sim→real
  video transfer (2605.02757); REALM (2512.19562); StaticEmbodiedBench
  (2508.06553); VLNVerse (2512.19021); Rethinking-Practicality (2602.22663);
  WoW embodied world-model Turing test (2601.04137); LIBERO / CALVIN /
  MetaWorld MT50 / RoboCasa / RoboTwin; AGIBOT Genie Sim 3.0.)*

## 8. Applications: Navigation, Driving, Dexterous & Humanoid

- ★ **Health-Conditioned VLA** (arXiv:2605.16056; see §1). The most
  deployment-honest entry of the cycle: real robots degrade, and a
  malfunction-aware policy that ingests a per-joint health vector and
  re-plans around a weak/locked joint is the kind of robustness the
  success-rate leaderboards never measure. A small, well-aimed conditioning
  interface for a real failure mode.

- **EchoVLA** (arXiv:2511.18112; see §3). As a *mobile-manipulation*
  application it is the cycle's clearest statement that crossing from tabletop
  to mobile requires persistent spatial + episodic memory, not just a bigger
  context window.

- **DuoCore-FS: Asynchronous Fast-Slow VLA Policies** (arXiv:2512.20188;
  carried highlight). Fast (action) and slow (VLM reasoning) pathways at
  *independent frequencies* — the systems fix that pairs with VLA-Perf (§7).

- **Vision-Language-Action Models for Autonomous Driving: Past, Present,
  Future** (arXiv:2512.16760; carried). The reference survey for the driving
  branch.

- **LeVERB: Humanoid Whole-Body Control with Latent VL Instruction**
  (arXiv:2506.13751; carried). Latent VL-instruction conditioning for
  high-DoF humanoid control — humanoid counterpart to WholebodyVLA (§5).

- *(Carried application anchors: METIS — egocentric dexterous VLA
  (2511.17366); ABot-N0 navigation foundation model (2602.11598); AIR-VLA
  aerial manipulation (2601.21602); DexVLA (2502.05855).)*

## Cross-Cutting Theme — memory becomes architecturally first-class (and gets a benchmark)

If the last two cycles pushed *structure into the conditioning interface*
(geometry, gesture, visual primitives), this cycle moves to the policy's
**temporal/state axis**: what the policy *remembers between steps* is being
designed deliberately instead of left to a sliding context window.

1. **Memory moves inside the decoder.** EvoScene-VLA (2605.21862) carries a
   recurrent, action-updated *scene belief* across action chunks, predicting
   future scene features so geometry survives self-induced occlusion and
   object motion. Memory here is not a retrieval store but a piece of decoder
   state — and it doubles as a feature-space world model (§4).

2. **…and also becomes an explicit, factored store.** MEM (2603.03596) splits
   memory by *granularity* (video short-horizon + text long-horizon, ~15-min
   horizons); EchoVLA (2511.18112) splits it by *kind* (scene vs. episodic)
   for mobile manipulation. The in-decoder vs. external-store and the
   granularity vs. kind factorizations are the two clean design axes the
   memory line now has.

3. **Memory finally gets a yardstick.** RoboMME (2603.04639) turns "our policy
   remembers" into a measurement — four memory types (temporal, spatial,
   object, procedural), non-Markovian by construction, 14 variants on a π0.5
   backbone. LARY (2604.11689) does the analogous service for latent-action
   *generalization*, and LIBERO-CF for language-following under counterfactuals.

4. **Robustness conditioning shows up.** Health-Conditioned VLA (2605.16056)
   conditions on a per-joint health vector — a reminder that the deployment
   distribution includes a *broken robot*, and the policy interface should
   admit that.

The natural next combinations: **EvoScene-VLA's in-decoder scene belief ×
RoboMME's non-Markovian suites** (the cleanest test of whether implicit
in-decoder memory matches explicit stores on the four memory types), and
**MEM/EchoVLA factored memory × VLAs-as-Tools decomposition** (give the
high-level planner the episodic store so it improves over a deployment
lifetime, dispatch geometry-aware short-horizon memory to the executor).

## Picks of the day (if you only read three)

1. **EvoScene-VLA (2605.21862)** — the freshest design and the cycle's
   cleanest unification: a recurrent, geometry-aware *scene belief* inside the
   action decoder that fuses memory, an in-the-loop world model, and 3D
   structure. It fixes the real failure of chunked policies — the world
   changes between visual updates — at the right layer.

2. **RoboMME (2603.04639)** — the memory benchmark the field needed. A
   four-way memory taxonomy on non-Markovian tasks with 14 memory-augmented
   π0.5 variants. If you work on VLA memory, this is now your evaluation
   substrate; read with MEM and EchoVLA for the representation side.

3. **MEM (2603.03596)** — the best *representation* argument for memory:
   multi-scale, mixed-modal (video short-horizon + text long-horizon),
   demonstrated on ~15-minute-horizon tasks with in-context strategy
   adaptation. The clearest answer to "what should a long-horizon policy
   remember, and at what resolution."

## Open backlog for the next cycle (to watch)

- **In-decoder vs. external memory, head-to-head** — EvoScene-VLA's recurrent
  scene belief (2605.21862) vs. MEM/EchoVLA's explicit stores (2603.03596 /
  2511.18112), evaluated on RoboMME's four memory types (2603.04639). Nobody
  has run that comparison on a common axis yet.
- **Feature-space world models as memory** — EvoScene-VLA's Scene Predictor
  predicts *future scene features* rather than pixels; pairing that with
  VLA-MBPO's in-imagination RL (2603.20607) is the obvious experiment for a
  geometry-aware, memory-carrying imagined rollout.
- **Latent-action generalization, measured** — LARY (2604.11689) should be run
  against the ALAM/JALA/UniVLA family so the latent-action line gets the same
  measurement discipline RoboMME brings to memory.
- **Robustness-conditioned policies at eval** — Health-Conditioned VLA
  (2605.16056) hints at a missing benchmark axis: success under hardware
  degradation. The practicality surveys (2604.23001) and CEBench should add a
  malfunction track.
